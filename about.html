사이트 소개

사진 한 장을 더 가볍게

파일서랍은 별도 프로그램 설치나 회원가입 없이 사진 용량을 줄일 수 있는 웹 도구입니다. 이메일 첨부나 웹 업로드 전에 파일 크기를 조절하는 번거로움을 줄이기 위해 만들었습니다.

현재 제공하는 기능

JPG·PNG·WebP 사진을 선택하고 품질을 조절해 JPG 또는 WebP로 저장할 수 있습니다. 가로·세로 픽셀 수는 유지하며 원본과 결과 용량, 결과 미리보기를 제공합니다.

운영 원칙

사진 처리는 사용자의 브라우저에서 수행합니다. 실제로 사용할 수 있는 기능과 제한을 명확하게 안내하고, 문제가 있으면 문의를 통해 개선합니다.

About File Drawer

Make a photo lighter

File Drawer is a browser tool for reducing photo file sizes without installing software or creating an account. It helps prepare images for email attachments and web uploads.

Available today

Choose a JPG, PNG, or WebP image, adjust quality, and save as JPG or WebP. Pixel dimensions stay the same, with original and output sizes and a result preview.

How we work

Image processing takes place in your browser. We explain available features and limits and welcome reports to improve the tool.

Operated by the File Drawer site operator.
