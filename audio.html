영상에서 소리만 저장하세요.

유튜브 링크, 기기 파일 또는 직접 영상 파일 주소를 선택하세요.

유튜브 음원 추출 · 시험 운영 중

유튜브 링크를 넣고 MP3로 저장하세요. 접근 코드는 필요하지 않습니다.

  • 최대 5분 길이의 영상 한 개를 MP3로 변환합니다.
  • 사이트 전체 이용자를 합쳐 하루 3회까지 제공됩니다. 한국 시간 자정에 횟수가 초기화됩니다.
  • 접수된 변환 요청은 실패해도 하루 횟수에 포함됩니다. 한도 또는 무료 크레딧이 부족하면 일시 중단됩니다.
  • 본인이 만들었거나 다운로드·변환을 허락받은 영상만 이용해 주세요.
  • 입력한 링크는 Cloudflare를 통해 SocialKit에 전달되고, 변환 파일은 업체의 임시 저장소에서 내려받습니다. 다운로드 링크는 약 1시간 동안 유효합니다.

MP3 다운로드

영상 파일 또는 직접 파일 URL

MP4 · MOV · WebM 등 / 최대 100MB. 코덱에 따라 지원 여부가 달라집니다.

유튜브·인스타그램 등의 페이지 주소는 지원하지 않습니다. 외부 접근을 허용한 HTTPS 영상 파일 주소만 사용할 수 있습니다.

음원 다운로드 ↓

영상 파일 기능의 사용 방법과 제한

파일을 선택하거나 영상 파일 주소를 입력한 뒤 형식을 고르고 추출하세요. 완료되면 미리 듣고 다운로드할 수 있습니다.

첫 실행 시 외부 CDN에서 약 31MB의 처리 도구를 내려받습니다. 파일 내용은 서버에 업로드하지 않고 내 브라우저에서 처리합니다. URL 입력 시에는 영상 제공 서버에 직접 접속합니다.

최대 100MB, 한 번에 한 파일을 처리합니다. 긴 영상은 최대 5분 처리 후 중단되며, 휴대폰에서는 메모리 부족으로 실패할 수 있습니다. 짧은 영상부터 시작하세요.

첫 번째 오디오 트랙을 MP3 또는 M4A로 변환합니다. 원본 파일은 바뀌지 않으며, 오디오 트랙이 없는 영상은 추출할 수 없습니다.

영상 파일에서 소리만 저장하는 순서

기기에 저장된 짧은 영상을 선택한 뒤 MP3 또는 M4A를 고르세요. 추출이 끝나면 미리 듣고 파일을 내려받으세요.

파일 확장자가 MP4여도 안에 든 코덱에 따라 처리할 수 없는 경우가 있습니다. 오디오 트랙이 없는 영상에서는 소리를 추출할 수 없습니다.

휴대폰에서 실패하면 더 짧은 영상이나 컴퓨터로 시도하세요. 최대 100MB 제한은 로컬 파일 도구에 적용되며, SNS 도구의 무료 크레딧 제한과는 별개입니다.
