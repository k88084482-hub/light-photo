사진 파일

선택한 사진과 압축 결과는 브라우저 메모리에서 처리하며 사이트 운영자 서버로 업로드하지 않습니다. 페이지를 닫으면 이 페이지의 처리 상태는 사라집니다. 다운로드한 파일은 사용자 기기에 남습니다.

언어 설정

한국어·영어 선택을 기억하기 위해 브라우저 로컬 저장소에 file-drawer-language 값을 저장합니다. 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다.

호스팅과 접속 정보

사이트는 Cloudflare Pages로 제공됩니다. 페이지 전달과 보안을 위해 Cloudflare가 IP 주소, 요청 시간, 브라우저 정보 등 접속 데이터를 처리할 수 있습니다. 사진 내용은 이 접속 정보에 포함해 전송하지 않습니다. 관련 처리는 Cloudflare 개인정보처리방침을 참고하세요.

광고 및 분석

현재 사이트 코드에는 광고나 별도 방문자 분석 스크립트를 설치하지 않았습니다. 추후 도입 시 실제 처리 방식에 맞게 안내와 필요한 선택 기능을 업데이트합니다.

문의 정보

이메일로 문의하면 발신 주소와 보낸 내용이 이메일 서비스에서 처리되며, 운영자는 답변과 문제 해결을 위해 사용합니다. 민감한 정보나 개인 사진을 불필요하게 보내지 마세요. 문의 기록의 삭제 요청은 문의 페이지의 연락처로 보내주세요.

변경 및 연락

기능과 정보 처리 방식이 바뀌면 이 페이지를 갱신합니다. 개인정보 관련 질문은 문의 페이지를 이용해주세요.
